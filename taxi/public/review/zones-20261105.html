Доработка нашего редактора зон

Перенос всего map-polygon не требуется. В существующий редактор добавлены недостающие действия, а сохранение через API такси и проверка геометрии сохранены.

  • Кнопка разворачивания карты на весь доступный экран и возврат к форме. Правки и положение карты сохраняются; выход также работает по Escape.
  • Вместо стандартной OSM-подложки используется общий векторный стиль Drive Morocco из приложения такси.
  • Перетаскивание вершин полигона с сохранением замкнутого контура.
  • Вставка вершины через + между точками и удаление выбранной вершины. У замкнутого контура остаётся минимум три вершины.
  • Перетаскивание центра круга, ползунок радиуса и ввод точного значения в метрах.
  • Первоначальное отображение всей редактируемой фигуры. При дальнейших изменениях положение карты сохраняется.
  • Любое изменение геометрии отменяет прежнее подтверждение сохранения. Заблокированную или сохраняемую зону нельзя менять через маркеры.

Попробовать демо без записи на сервер · Редактор для администратора

Демо использует только заданные тестовые фигуры на странице. Кнопка сохранения в демо показывает результат локально. В административном редакторе запись по-прежнему выполняется через существующий API после подтверждения.

Проверено: 1057 тестов, TypeScript, проверка обработчиков заказа и браузерные сценарии при ширине 1280 и 390 пикселей. В браузере проверены перетаскивание, вставка, удаление, замыкание, радиус, повторное подтверждение и блокировка редактирования. Рабочие зоны и общая БД не изменялись.

Поиск пересечений между зонами и редактирование нескольких контуров в эту доработку не входят. Переводы новых подсказок могут поступать из словаря сервиса; встроенные тексты служат запасным вариантом. Восстановление прежнего набора языков тенанта остаётся отдельным пунктом.
