Эмулятор водителей встроен в проект.

Как запускать:
1. Распакуй архив проекта.
2. Запусти проект обычной командой: npm start
3. Вместе с dev-сервером автоматически поднимется локальная панель эмулятора на http://127.0.0.1:3099
4. Зайди на сайт под водителем.
5. Открой левое меню -> Эмулятор водителей.
6. Внутри сайта откроется панель: Запустить / Остановить / Проверить / Один проход.

Если нужно отключить автозапуск панели при npm start:
set START_DRIVER_EMULATOR_PANEL=0
npm start

Если панель не отвечает, можно вручную запустить:
driver-emulator\panel-background.bat
