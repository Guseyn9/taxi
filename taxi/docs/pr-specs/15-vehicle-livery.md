# 15. Ливрея машины отдельно от темы UI

## Замечания

Валентин: цвета зависят от локации; 31.10 09:23 — Grand отличается узнаваемой расцветкой. Контуры Petit/Grand приняты ранее, не рисуем один седан для обоих.

## Изменение

- Сохраняем компактный Petit и длинный Grand. Petit Агадира — ранее подтверждённый красный.
- Grand — светлый кузов с синей боковой полосой, отдельный от красного Petit. Визуальный ориентир: [описание транспорта Агадира](https://www.airportaga.com/fr/se-deplacer-agadir/), Grand crème/jaune с синей полосой. Это визуальный fallback, не серверная лицензия.
- Цвет кузова и тип передаются в карточку и движущийся маркер. Маршрутные цвета водителей остаются независимыми.
- Не использовать сохранённый тестовый город камеры для определения рабочей расцветки.
- `classPalette` имеет приоритет для класса; до появления отдельного поля конфигурации Grand использует bundled fallback. Общая service palette не должна превращать Grand в Petit.
- Нет переключателя между нашей темой и темой сервиса. UI остаётся красно-чёрным с рыжим акцентом.

## Приёмка

1. В Агадире Petit красный, Grand светлый с синей полосой; разные контуры.
2. В карточке и на карте один класс использует одну расцветку.
3. Переключение тестовой камеры не перекрашивает машины.
4. Недопустимая строка цвета не попадает в SVG; окна, колёса, прозрачность сохранены.
5. Другим городам не назначаем неподтверждённые соответствия. Для полной городской матрицы нужен подтверждённый справочник классов/цветов сервиса.
