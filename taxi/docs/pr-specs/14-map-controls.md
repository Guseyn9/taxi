- «Развернуть карту» убирает sheet; повторная кнопка/Escape возвращает форму с прежним состоянием. Без запроса browser fullscreen разрешений.
- На мобильном убрать +/−, pinch оставить. Desktop zoom сохранить.

1. Нет dropdown городов в рабочей карте; тестовая смена не меняет payload заказа.
2. Ручное перемещение + From/To дают точку под видимым локатором, в том числе desktop.
3. Раскрыть/закрыть карту 3 раза, Escape: состояние формы сохранено, карта пересчитала размер.
4. На mobile отсутствуют кнопки zoom; жесты работают. GPS работает независимо от тестового города.
5. Упавший WebGL не блокирует форму; OSM attribution остаётся видимой.
