Источник: https://github.com/Guseyn9/taxi/pull/35. ТЗ уточнено 31.10.2026 по замечаниям Валентина.

## Проблема

Перезагрузка, потеря сети и терминальные состояния не должны смешивать заказы.

## Объём

- Привязать цену/ETA/режим к конкретному заказу.
- Offline/pending/error состояния.
- Восстановление выбранной поездки; несколько заказов.

## Приёмка

- Перезагрузка, отмена/завершение подряд, отсутствие устаревшего выбранного водителя.
- Не подставлять выдуманную цену или ETA при отсутствии поля.
- Серверный посадочный код не объявлять проверенным без API теста.

## Граница
