# 19. Кнопки, геопозиция и параметры поездки

Основание: три скриншота пользователя от 31.10, 20:19–20:21. Отдельная ветка поверх PR #49. Backend и команда заказа не меняются.

## Что исправить

1. Иконка каждого способа заказа должна быть по центру подписи. Убрать односторонний отступ SVG; сохранить отдельную кнопку справки.
2. «Откуда»/«Куда» собрать в одну компактную группу. Голосовой ввод разместить отдельной строкой, без пересечения с fullscreen/zoom. При выборе точки показывать только управление выбором.
3. При отказе GPS показать короткое сообщение, выбор на карте, повтор запроса и раскрываемую инструкцию. Кнопка сайта не должна обещать снять запрет браузера.
4. При входе в параметры карточки машин должны быть целыми. Вторичный экран использует доступную высоту; заголовок и «Готово» остаются на месте, прокручивается только содержимое при нехватке места. Справку о классах перенести к заголовку выбора машины. Заменить старые растровые стрелки и часы едиными SVG.

## Сравнение геолокации

В исходнике `Map/index.tsx` запускает Leaflet `map.locate` при создании карты и смене `defaultCenter`, с `timeout: Infinity`. Ошибка игнорируется. Периодический запрос выполняется и после отказа; у него нет ограниченного timeout.

У нас первый запуск сохранён: при `prompt` браузер получает запрос и решает, показать ли системное окно. При `granted` запрашиваются координаты. Сохранённый `denied` не вызывает повторный стартовый запрос. В браузерах без Permissions API и при ошибке preflight используется обычный запрос геолокации.

Исправления этой ветки:

- Стартовый запрос один на экземпляр карты; смена маршрута его не повторяет.
- Отложенный preflight отменяется при отключении карты. Во время запроса кнопка GPS занята.
- Timeout 10 секунд, high accuracy, `maximumAge: 0`; явное нажатие снова запрашивает свежие координаты.
- Автоматический опрос не идёт после отказа и в скрытой вкладке. Обработчики отправки координат водителя не менялись.
- Если координаты вне Марокко, камера не прыгает к границе региона. Сообщение предлагает выбрать место посадки на карте. Это не замена серверной проверке зоны.
- Выбор на карте открывает существующий выбор точки. До подтверждения адрес не меняется.

## Приёмка

- Проверить 320×568, 390×844, 768×1024, 844×390, 1440×900.
- Центр иконки совпадает с центром подписи; нет перекрытия с иконкой справки.
- В параметрах виден верх обеих карточек, «Готово» доступно; на коротком экране допустима одна прокрутка содержимого.
- Отказ GPS → карта; повтор запроса → ошибка/координаты; инструкция раскрывается отдельно.
- Unit: granted/prompt/denied, отсутствие/ошибка Permissions API, отмена отложенного запроса, busy, выбор карты без GPS.
- TypeScript, production build и проверка неизменности backend-команд.

Системный диалог разрешения и точность GPS на физических телефонах требуют отдельной проверки владельцем устройства. Изменение разрешений браузера автоматикой не выполнялось.
