# PR #33: Безопасная обработка данных

Источник: https://github.com/Guseyn9/taxi/pull/33. ТЗ уточнено 31.10.2026 по замечаниям Валентина.

## Проблема

Данные заказа не должны исполняться как JavaScript; FormData не теряет 0/false.

## Объём

- Ограниченный арифметический интерпретатор вместо eval.
- Санитизация HTML и проверка URL.
- Сохранение нулей и логических значений в запросах.

## Приёмка

- Выражения с вызовами JS отклоняются.
- XSS payload не исполняется.
- 0/false уходят как значения, а не исчезают.

## Граница

Backend/FSM/БД, main и права доступа не меняем. Предыдущие результаты в описании PR относятся к его ревизии; актуальный общий прогон фиксируется отдельно.
