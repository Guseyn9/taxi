# PR #34: Дорожный граф и расчёт выгоды

Источник: https://github.com/Guseyn9/taxi/pull/34. ТЗ уточнено 31.10.2026 по замечаниям Валентина.

## Проблема

Граф нужен для регулярного локального расчёта доходности, а не только fallback API.

## Объём

- Сохранить алгоритм Дейкстры и бизнес-формулу.
- Загрузка/разбор графа в Worker.
- Версионированный persistent cache подготовленного графа; дедупликация запросов.

## Приёмка

- Cold/warm/повторное открытие, несовпадение версии, повреждённый кеш.
- Без Worker/IndexedDB допустимый fallback, освобождение ресурсов.
- Проверка равенства расчётов исходному графу.

## Граница

Backend/FSM/БД, main и права доступа не меняем. Предыдущие результаты в описании PR относятся к его ревизии; актуальный общий прогон фиксируется отдельно.
