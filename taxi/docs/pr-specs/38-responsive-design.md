# PR #38: Дизайн без изменения бизнес-правил

Источник: https://github.com/Guseyn9/taxi/pull/38. ТЗ уточнено 31.10.2026 по замечаниям Валентина.

## Проблема

Редизайн сохраняет функции, а не только внешний вид.

## Объём

- Manrope, красный основной, чёрный/белый, рыжий акцент.
- Клиент: плашки нескольких заказов с переключением.
- Водитель: Кратко до 6 карточек, Все с деталями, Карта.
- Разделять цену заказа, выгоду и выгоду на км подачи; цвета маршрутов сохраняются.

## Приёмка

- Нельзя потерять доступность Vote/Offer и ключи БД.
- Не закрывать откликнувшихся водителей большой панелью адресов.
- Кнопки/карточки не обрезаются, tap target >=44px.
- Дальнейшие исправления регрессий вынесены в PR11–15 этой серии.

## Граница

Backend/FSM/БД, main и права доступа не меняем. Предыдущие результаты в описании PR относятся к его ревизии; актуальный общий прогон фиксируется отдельно.
