## Замечание

31.10 09:30/09:36: тексты живут в БД; Vote/Offer обойдены локальным словарём.

## Изменение

- Убрать принудительный приоритет bundled текста в `t()` и замену слова «Предложение».
- Поиск: ID языка, точный ISO, базовый ISO, fallback сервиса, затем packaged fallback.
- Дизайн-обёртки запрашивают существующие `vote`, `to_order`, `client_offer_short_button`, `client_offer_order_button`, `client_offer_hint`; дополнительные UI-ключи `booking_ui_*`/`service_ui_*` имеют offline fallback.
- Категории маршрута показывают реальные переводы класса, без собственного списка коротких названий.
- БД не менять. Новые необязательные ключи можно добавлять в БД отдельной задачей автора сервиса.

## Приёмка

1. Значение БД для Vote/Offer/подсказки отображается дословно даже при наличии packaged перевода.
2. ar-MA/fr-FR читают базовый ISO, если нет точного/ID.
3. При недоступной конфигурации есть понятный offline текст.
4. Имена моделей из справочника не переписываются.
5. Изменение словаря не меняет payload режима.
