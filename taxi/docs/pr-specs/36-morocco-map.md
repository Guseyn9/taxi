# PR #36: Карта и движение

Источник: https://github.com/Guseyn9/taxi/pull/36. ТЗ уточнено 31.10.2026 по замечаниям Валентина.

## Проблема

Карта показывает Марокко, машины следуют координатам без дрожания и принудительного возврата камеры.

## Объём

- Границы Марокко, ограниченный zoom, fallback карты.
- Интерполяция движения и кратчайший поворот, очистка animation frame.
- Сохранить запрос геолокации при старте карты и по кнопке; retry/denied/help, без обхода разрешений.

## Приёмка

- Смена маршрута, устаревший GPS, скачок координат, reduced motion.
- Неверные/нулевые координаты не приводят к падению.
- Mobile map picker заполняет viewport без нижней пустой полосы.

## Граница

Backend/FSM/БД, main и права доступа не меняем. Предыдущие результаты в описании PR относятся к его ревизии; актуальный общий прогон фиксируется отдельно.
