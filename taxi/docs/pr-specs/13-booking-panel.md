# 13. Нижняя панель клиента

## Основание

31.10 10:10: свёрнутая форма потеряла обязательные поля и defaults; расширенная закрывает карту. Ранее: прыжки вёрстки, перекрытые отклики, пустота под map picker.

## Изменение

- Мобильный старт — компактная полезная форма: два адреса, сводка времени/мест/класса и прямые команды заказа.
- Убрать «Развернуть форму» как единственное содержание. Handle остаётся доступной кнопкой раскрытия/сворачивания.
- Убрать повторные заголовки на телефонах. На широких экранах сохранить контекст.
- Ручной класс географии перенести в параметры; до хотя бы одной заданной точки не показывать. Камера не определяет класс.
- Параметры содержат класс/машину/места/время/комментарий/телефон; «Готово» возвращает к прежнему виду и фокусу.
- Сохранить отдельную карточку откликов и плашки нескольких активных заказов.

## Приёмка

- 320×568, 360×640, 390×844, 768×1024, 844×390, 1440×900.
- Компактная форма не исчезает при свайпе; поля доступны без раскрытия.
- На мобильном карта занимает не меньше оставшейся половины рабочего viewport в компактном режиме; footer не перекрывает поле.
- Параметры ограничены по высоте, карта остаётся доступной. При клавиатуре/увеличенном шрифте допускается одна прокрутка содержимого, без обрезания кнопок.
- Раскрытие/закрытие не меняет адрес, цену, выбранный заказ или тип запроса.
