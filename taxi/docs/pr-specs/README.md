## Инварианты

1. Vote — поездка на первом прибывшем такси; междугородний Vote недоступен. Не переименовывать механику в обычный выбор водителя.
2. Все три способа сохраняют исходные payload/FSM; конечный submit проверяет допустимость независимо от UI.
3. Клиент может держать несколько заказов; выбранный заказ владеет ценой/валютой/ETA/режимом.
4. Краткий вид водителя сохраняет до 6 заказов; расчёт выгоды локальный, граф необходим. Цвет линии различает водителей и не является цветом кузова.
5. Локация определяется сервисными полигонами. Ручной город — тест камеры; не записывает геопозицию и не выбирает рабочую палитру.
6. Тексты БД имеют приоритет; bundled словари только fallback. Нет переключателя палитр. Интерфейс и ливрея такси — разные сущности.
7. Карта остаётся видна при подаче/откликах. Параметры редактируются отдельно, маленькие экраны допускают доступную прокрутку при увеличенном шрифте/клавиатуре вместо обрезания.
8. Геолокация не может обойти запрет браузера. Повторный запрос и инструкция обязательны, разрешение не выдаём программно.
9. Демо явно обозначено и не создаёт настоящих заказов. Пул анонимов, lease/TTL и запрет реальных заказов обеспечиваются сервером.
10. Нельзя объявить пилот 200–400 водителей готовым по unit/fixture тестам.
