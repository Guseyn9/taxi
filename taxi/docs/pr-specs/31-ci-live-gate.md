# PR #31: Изоляция live CI

Источник: https://github.com/Guseyn9/taxi/pull/31. ТЗ уточнено 31.10.2026 по замечаниям Валентина.

## Проблема

Черновые PR не должны запускать поездки на общем backend.

## Объём

- Пропуск live E2E для draft PR.
- Запуск при ready_for_review; ручной запуск сохраняется.
- Не менять основную бизнес-логику.

## Приёмка

- Draft: job skipped; после ready: job допускается.
- Изменение main и выдача прав отсутствуют.

## Граница

Backend/FSM/БД, main и права доступа не меняем. Предыдущие результаты в описании PR относятся к его ревизии; актуальный общий прогон фиксируется отдельно.
