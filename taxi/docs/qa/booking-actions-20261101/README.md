# Кнопки заказа — 01.11.2026

Проверка пройдена в пределах этого изменения.

- Три действия различаются заливкой и текстом: красное, тёплое белое, почти чёрное. До заполнения маршрута сохраняются читаемые контрастные варианты, но отправка по-прежнему заблокирована.
- Маленькие вопросики убраны. Вместо них одна отдельная кнопка «Как заказать?» высотой 44 px. Она объясняет все доступные способы и не отправляет заказ.
- Вся карточка действия нажимается. Содержимое имеет высоту 96 px; на узком экране подписи переносятся без обрезки.
- На коротком телефоне повторный выбор класса перенесён в «Параметры поездки»; текущий класс остаётся в сводке. В параметрах доступны оба класса.

## Проверки

- 712 тестов / 142 набора: пройдены. TypeScript и production build: пройдены. После финальной CSS-коррекции preview пересобран.
