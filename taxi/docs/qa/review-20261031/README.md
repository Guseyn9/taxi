# Проверка frontend после комментариев Валентина

31.10.2026. Сборка: цепочка `review/11-service-localization` → `review/17-acceptance-evidence`, включая голосовой PR #41 на a0a17cd. Main, backend и БД не изменены. Реальные заказы не создавались.

## Результат

- Чистая установка из lockfile: 2115 пакетов, `npm ci --ignore-scripts --no-audit --no-fund` прошла в отдельной папке.
- 708 теста / 141 наборов; TypeScript и production build прошли после уточнения карты и параметров.
- Проверка границ: 229 исходных core-файлов и 64 бизнес-обработчика совпали с baseline; намеренные frontend-отличия перечислены инструментом, неизвестных отличий нет. Это не security-аудит backend.
- Браузер: 320×568, 360×640, 390×844, 768×1024, 844×390, 1440×900. У формы нет горизонтального переполнения, footer не обрезан. На коротких экранах и с увеличенным текстом дополнительные параметры/регистрация используют доступную прокрутку.
- Реальные телефоны, GPS на улице, микрофон, потеря сети во время серверной поездки и нагрузка 200–400 водителей не проверены.

## Что изменено по замечаниям

| Замечание | Решение / доказательство |
|---|---|
| Переводы хранятся в БД, нельзя подменять Vote/Offer | `t()` отдаёт значение сервиса первым; сохранены исходные ключи. Новые UI-ключи имеют только fallback. Тесты проверяют дословный приоритет БД и regional ISO. |

| Кузов по классу/локации, Petit и Grand различны | По новым фото Валентина: красный компактный Petit и высокий бело-жёлтый Grand с шашечной полосой. Отдельные изображения в карточках и сверху на карте. Полную матрицу остальных городов должен передать сервис. |

## Уточнение иконок после получения фото

Валентин передал реальный ПЕТИТ и ГРАНД. ПЕТИТ — красный компактный хэтчбек без оранжевой полосы. ГРАНД — высокий бело-жёлтый автомобиль с шашечной полосой. Прежние кадры выше относятся к предыдущей ревизии иконок. Актуальные боковые изображения и виды сверху: [ТЗ 18](../../pr-specs/18-approved-vehicle-icons.md), [галерея](/review/vehicle-icons-20261031.html). Эти два референса Агадира подтверждены автором; палитра других городов ещё требует справочника. API и движение не менялись.

Актуальные кадры: [четыре иконки](approved-vehicle-icons.png), [карточки на телефоне](approved-vehicles-client-390.png), [вид сверху на карте водителя](approved-vehicle-map.png). В начальной форме без выбранного адреса синий цвет общей темы больше не подменяет красный ПЕТИТ.

## Что требуется от backend / автора сервиса

| Приоритет | Задача | Приёмка |
|---|---|---|
| P0 | Проверка посадочного кода сервером; явно описать отличие эмулятора | 000 вместо верного 111 не запускает обычную поездку; тестовые исключения изолированы. |
| P0 | Подтвердить Offer-контракт: создание, цена клиента, ответ водителя, принятие | Короткий маршрут Агадира: клиент 150 → водитель 180 → принятие → поездка; обе стороны видят один режим/сумму. Указать успешный запрос/ответ и случаи нулевой цены. |
| P0 | Единое поле ETA, единицы и авторитет времени | Выбранные водителем 5 минут одинаковы у клиента после polling/reload. Сейчас frontend не подставляет вместо отсутствующего ETA выдуманные 15 минут. |
| P0 | Фильтры лицензии/класса/мест/географии на сервере | Petit не получает неподходящий междугородний заказ и не может принять его прямым запросом. Frontend-фильтр не заменяет авторизацию. |
| P0 | Отдельный стенд/аккаунты/фикстуры и CI изоляция | Три поездки с двух ролей, повтор завершений/отмен, код посадки и disconnect не затрагивают реальные заказы. |
| P1 | Настройки Марокко | Согласовать валюту, телефон и дефолтную сервисную зону. Текущий сервис по-прежнему отдаёт GHS/+233; фронт не маскирует их как MAD/+212. |
| P1 | Справочник ливреи `(зона, класс)` | Передать полную палитру остальных городов; вернуть документированный класс/цвет. Не использовать camera preset как географию обслуживания. |
| P1 | Локализация БД / адресные метаданные | Заполнить тексты для ru/fr/ar/en; в текущих данных встречаются `Waiting` и локальные многоязычные названия. Передавать `name:locale` либо однозначное локализованное представление; frontend сохраняет исходный адрес и координаты. |
| P1 | Пул гостевых аккаунтов | Атомарно занять свободный аккаунт на роль, отказать при исчерпании пула, heartbeat/TTL/release. Существующие метки тестовых заказов сохранить. Пароли не отдавать в frontend bundle. |
| P1 | Реальная доступность машин | Авторитетные count/ETA, понятное отсутствие данных; постоянные «7 машин / 5 минут» не возвращать. |
| P1 | Нагрузка 200–400 водителей и мобильный приёмочный прогон | Измерить p95 задержек/ошибки polling/socket; потеря связи, background/foreground, несколько заказов и восстановление. Реальный GPS и speech на Android/iOS. |
