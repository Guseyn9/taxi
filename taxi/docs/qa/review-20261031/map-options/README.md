# Кнопки, геопозиция и параметры — 31.10.2026

- Иконки способов заказа: смещение от центра кнопки 0 px у всех трёх действий; справка остаётся отдельной кнопкой.
- Карта: компактная группа «Откуда»/«Куда», отдельный голосовой ввод. На экране параметров управление картой скрыто.
- Параметры: карточки машин целые, заголовок и «Готово» доступны на всех пяти размерах. Поле телефона больше не растягивает середину формы. На 390×844, 768×1024 и 1440×900 прокрутка содержимого не нужна; на 320×568 и в альбомном 844×390 остаётся одна прокрутка содержимого. Нет горизонтального переполнения.
- GPS: в браузере проверены сохранённый отказ, повтор запроса и переход к выбору посадки без GPS. До подтверждения точки адрес не меняется. Сайт не может снять браузерный запрет самостоятельно.
- 703 теста / 140 наборов, TypeScript, production build и проверка backend boundary прошли. Отправка заказа и водительских координат не менялась.

Исходник: стартовый `map.locate` при появлении карты/смене центра, timeout Infinity, ошибка игнорировалась. У нас запрос при первом появлении карты сохранён, timeout ограничен 10 секундами; повтор при смене маршрута удалён. Сохранённый отказ не запускает фоновую серию запросов. Нажатие GPS использует свежие координаты (`maximumAge: 0`).

Permissions API проверен тестами: prompt, granted, denied, отсутствие API, отклонённый Promise, синхронная ошибка WebView, отмена отложенного запроса. UI: busy и отдельный выбор карты. Координаты вне Марокко не перемещают камеру к границе и не выдаются за запрет доступа.

Физические телефоны, системный диалог разрешения, точность GPS и успешное получение реальных координат здесь не проверены. Разрешения браузера автоматикой не менялись. Backend-запросы заказа не выполнялись.
