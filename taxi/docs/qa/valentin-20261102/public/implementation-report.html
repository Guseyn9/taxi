Проверки и ограничения

  • 751 тест / 152 набора прошли. Проверены регрессии frontend, а не нагрузка сервера.
  • TypeScript без ошибок; производственная сборка и проверка границ backend прошли. Файлы результатов и скриншоты находятся в reports/valentin-20261102 вне исходного checkout.
  • Реальный браузер, отдельный чистый локальный origin: network → IndexedDB после перезагрузки, 69 892 узла. Холодно: worker 254,7 ms, JSON 14,0 ms, подготовка 76,1 ms, подключение UI 0,1 ms. Повторно: worker 10,2 ms, JSON 0 ms, подготовка 0 ms. Это настольный CPU, не Android и не время отклика backend.
  • RAW benchmark, 100 событий при заполненном буфере: 100 синхронных записей заменены одной отложенной. 216,3 млн сериализованных символов → 2,13 млн. Замер на текущем компьютере не доказывает устранение исходного падения.
  • Формы проверяются настоящими компонентами на отдельной локальной странице. CSP запрещает отправку данных; серверный отказ там — имитация для проверки UI. Водительская схема сокращённая, не замена живой форме БД.
  • Кэш и граф проверены с настоящими Worker/IndexedDB и локальными файлами. Состояния заказа и адаптивность проверяются на локальных данных; фон карты в draft fixture явно обозначен заглушкой.
  • Во время проверки внешний сервер конфигурации не отвечал. Живые поездки Order/Vote/Offer, отправка регистраций, 200–400 водителей и физические телефоны в этот результат не входят.
