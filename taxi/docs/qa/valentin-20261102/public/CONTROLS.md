| Элемент | Компонент / правила |
|---|---|
| Текст / email | `Input`, подпись и звёздочка, aria-invalid и связанная ошибка. Email: сначала blur или submit, затем исправления проверяются при вводе. |
| Пароль | Тот же Input; кнопка показать/скрыть 44 × 44, aria-pressed; у водительской JSON-формы такое же действие. Значения не пишутся в новые диагностические события. |
| Телефон | `PhoneCountryField`, страна и маска; вставка +/00 определяет поддерживаемую страну. В форме хранится полный международный номер без разделителей. Существующий normalizePhoneNumber вызывается на прежнем месте. Страна телефона не меняет город поездки. |
| Страна / Select | Нативный select, не менее 44 px высотой, управление клавиатурой; подпись локализуется. Список поддерживаемых масок явно задан, неизвестный международный префикс сохраняется без обрезки. |
| Radio | Один способ входа. WhatsApp недоступен и помечен текстом. Не вызывает запросов. |
| Основная кнопка | Не менее 44 px, обычное / фокус / disabled / pending. Повторная отправка блокируется существующим submissionPending. |
| Восстановление пароля | Отдельная вторичная ссылка-кнопка с зоной 44 px; существующее подтверждение и запрос сохранены. |
| Ошибка | У конкретного поля, role=alert, aria-describedby. У формы заказа причина блокировки читается до нажатия. |
| Модальное окно | В пределах динамической высоты окна. Длинная регистрация может прокручиваться внутри; скрывать оставшиеся обязательные поля ради отсутствия полосы нельзя. У клиентской регистрации CTA выделен из прокручиваемой области. |

Водительская регистрация остаётся JSON-формой сервиса. Её поля, обязательность, фильтры моделей и серверные правила не заменены выдуманным статическим списком. QA использует сокращённую схему только для проверки контролов.

Новые тексты проходят через t/serviceText; серверный перевод имеет приоритет. Формы и причины ошибки проверяются отдельно от серверной регистрации и создания заказа.
