# PR20. Палитра первого варианта

Проблема: пользователь выбрал концепт с винной панелью, но текущая сборка использует чёрную панель.

## Требования
1. Винная поверхность формы, белые/фарфоровые поля, алые действия, спокойные бордовые вторичные элементы.
2. Общие семантические токены для приложения, public review и investor-демо.
3. Сохранить Manrope, размеры, размещение блоков, backend payloads, проверки доступности команд, ливреи городов и классов.
4. Отдельно проверить контраст, телефоны 320/390 px и альбомный режим.
5. Публикация только review-ветками, без main; Vercel production после успешных проверок.
