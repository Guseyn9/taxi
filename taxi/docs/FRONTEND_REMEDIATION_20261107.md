# Taxi Morocco: исправления frontend · 7 ноября 2026

Область: только frontend. Общий PHP backend и БД не изменялись. Ветка `fix/frontend-20261107` фиксирует текущие локальные исправления и изменения этой работы. Исходная локальная Git-база — `580a3bd`; аудит Валентина относится к другой базе `8cd07c9`. Его документация сохранена в `audit/frontend-inventory` и не переписывалась.

## Что изменено в этой работе

- Закрыты утечки Basic/Digest-авторизации, паролей и вложенных URL из диагностических строк. Данные очищаются на каждом уровне кодирования до повторного декодирования; посторонние ошибочные `%` не обходят очистку. Проверены все шесть экспортов.
- Карта получает тот же свежий GPS fix, который использует общий поток геолокации. Убраны отдельный запрос и блокировка перемещения более 450 м. Точка истекает по таймеру, сбрасывается при ошибке и восстанавливается с новым fix.
- Добавлена история поездок пассажира через существующий `/drive/archive`: загрузка, пустой результат, ошибка, повторная попытка, изоляция аккаунтов и игнорирование запоздалых ответов.
- Необязательное чтение дополнительных маркеров карты больше не вызывает необработанное отклонение Promise при отказе сети.
- Убран встроенный общий ключ ORS; без явно настроенного публичного browser key используется существующий переход к локальному графу/OSRM. OSRM fallback ограничен общим deadline для подключения и JSON body.
- Обновлены уязвимые зависимости. Для deepmerge, у которого нет опубликованной исправленной версии, включён минимальный локальный fork `lib/deepmerge`, с MIT-лицензией, происхождением и тестами prototype poisoning/совместимости. Номер локальной версии не означает upstream release.
- `npm run build:gruzvill` воспроизводимо переключает API и справочник вместе. Адаптировано разрешение runtime worker URL MapLibre для исправленного Webpack, без отключения предупреждений сборки.

## Проверки

Все 1170 тестов (212 suites) прошли; TypeScript, lint без ошибок, production gruzvill build, canonical entrypoints и точная проверка разрешённых изменений относительно upstream baseline прошли.
