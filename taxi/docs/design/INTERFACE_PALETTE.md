# Палитра интерфейса

Источник референсов — SCRN MCP, актуальная карточка InDrive от 21 марта 2026, просмотрена 30 октября 2026.

- Главная: https://scrn.gallery/app/indrive?screen=69bea1e6668d7f87ce1e102d
- Выбор точки: https://scrn.gallery/app/indrive?screen=69bea8d86340bf6c226b4a5d
- Тарифы: https://scrn.gallery/app/indrive?screen=69bea94d668d7f87ce1e2579

Применены: карта во всю доступную область, нижнее подтверждение рядом с краем экрана, чёткое выбранное состояние, спокойная подложка вокруг главного действия. Существующие три режима заказа сохранены.

Палитра: #B51218 красный действия и выбора; #910E13 наведение; #101010 основная чёрная поверхность; #E87516 рыжий для небольших акцентов и фокуса; подтверждение — красная кнопка с белым текстом; #FFF0ED светлое выбранное состояние; белые поля; нейтрально-серые подписи и карта. Manrope сохраняется. Цвет машин по локации независим от оформления интерфейса.

На чёрной форме режимы объединены в один блок: активный красный, остальные тёмные. Поведение запросов не меняется. Выбор точки использует оставшуюся высоту страницы без повторного 100dvh под шапкой. Высота реагирует на панель браузера и клавиатуру; масштабирование страницы не выключается.
