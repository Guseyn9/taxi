# PR22 — контраст действий и доступная справка

Проблема: важные действия сливались с панелью; маленькие вопросики трудно нажимать на телефоне.

Результат: три контрастных карточки и отдельная полноразмерная справка по доступным способам. Прямые команды, подтверждение своей цены, серверные поля и ограничения отправки сохраняются.

Приёмка: справка не создаёт заказ и не меняет режим; недоступный способ скрывается в карточках и объяснении; pending блокирует повтор; короткий экран показывает действия целиком; выбор класса остаётся в параметрах.

Доказательства: docs/qa/booking-actions-20261101/. 712 тестов, TypeScript, build и frontend boundary пройдены. Backend не изменён.
