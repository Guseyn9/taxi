Что исправлено:

1. Ошибка wrong user role при кнопке «Создать заказ» была из-за того, что отдельная Node-панель пыталась создать заказ через manager/admin аккаунт, а backend принимает создание заказа только от пользователя с ролью пассажира.

2. Кнопка «Создать заказ» в пассажирской панели теперь создает заказ прямо из текущей браузерной сессии пассажира через фронтовый API.postDrive. Поэтому используется реальный token/u_hash того клиента, под которым открыт сайт.

3. Отдельная panel.bat больше не пытается создавать заказ через manager-аккаунт. Если нажать создание заказа в отдельной панели, она честно пишет, что заказ нужно создавать из пассажирского сайта.

4. Эмулятор водителей не запускается автоматически. Водители стартуют только по кнопке «Запустить».

5. Основной gruzvill-флоу не тронут: водители дают отклики, пассажир сам выбирает, выбранный водитель едет, остальные скрываются.
