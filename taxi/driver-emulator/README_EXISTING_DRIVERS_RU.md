# Готово: запуск через существующих водителей

В этот архив уже внесены 2 готовых водителя в `config.json`.
Регистрацию новых водителей запускать не нужно.

## Как запускать

```bat
npm run check
npm start
```

Если `npm run check` покажет `Ready bots: 2/2`, симулятор готов.

Если будет `car not found for this driver`, значит у этого аккаунта нет машины в backend.
Если будет `wrong login` или `wrong password`, значит логин/пароль не подходит для API `/auth`.

## Важно

`npm run register` сейчас не нужен, потому что создание машины через backend у новых водителей падало на `database insert failed`.


## Разные координаты водителей

В `config.json` у каждого водителя можно указать свой блок `location`:

```json
"location": { "latitude": 47.221, "longitude": 39.633 }
```

Если координаты не указаны внутри конкретного водителя, симулятор берёт координаты из массива `driverLocations`. Если и его нет, симулятор автоматически разнесёт водителей вокруг общей точки `driverLocation`, чтобы они не стояли все в одном месте.
