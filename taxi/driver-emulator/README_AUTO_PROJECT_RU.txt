АВТОМАТИЧЕСКИЙ ЗАПУСК ЭМУЛЯТОРА ИЗ ПРОЕКТА

Главный вариант для проверки:
1. Открой driver-emulator/panel.bat.
2. Панель сама откроется и сразу запустит эмулятор.
3. Если готовых водителей меньше 5, эмулятор сам зарегистрирует недостающих тестовых водителей и сохранит их в data/registered-drivers.json.

Пользователю не нужно вручную запускать register.bat или npm run register.

Кнопка «Эмулятор водителей» в сайте управляет этой локальной панелью. Браузер сам не может запускать node.exe с диска, поэтому panel.bat всё равно надо открыть один раз.

Логика теста:
- offer/voting: водитель только появляется кандидатом, пассажир выбирает сам;
- первый водитель не выбирается автоматически;
- после выбора остальные кандидаты закрываются, выбранный водитель едет;
- водитель доезжает до клиента, ждёт, нажимает «на месте», стартует поездку, доезжает и завершает;
- для voting используется подбор кода 1-9;
- city и color при регистрации не отправляются, чтобы не ловить Db insert failed из-за лишних/fk-полей.
