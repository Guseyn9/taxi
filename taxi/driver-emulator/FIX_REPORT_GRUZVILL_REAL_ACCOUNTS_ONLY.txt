Исправление под gruzvill:

1. Эмулятор переведён на API gruzvill:
   https://ibronevik.ru/taxi/c/gruzvill/api/v1

2. Убрано автосоздание тестовых водителей. Эмулятор использует только аккаунты, указанные в driver-emulator/config.json.

3. Убраны старые локальные Test Driver из data/registered-drivers.json и отключена регистрация через bat-файлы.

4. Панель эмулятора больше не запускает симуляцию автоматически. Нужно открыть panel.bat и нажать "Запустить".

5. Убрана кнопка "Один проход" из панели.

6. Offer/voting отклики отправляются безопасно для gruzvill: в c_options уходит только performers_price, без driver_offer_eta и driver_offer_comment, чтобы backend не возвращал wrong c_options keys.

7. Ручной выбор сохранён: до выбора пассажиром водитель не едет, не нажимает "на месте" и не стартует поездку.
