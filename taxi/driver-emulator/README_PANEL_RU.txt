Панель эмулятора водителей

1. Запусти panel.bat или команду:
   npm run panel

2. Открой:
   http://127.0.0.1:3099

3. В панели можно нажать:
   Запустить — стартует постоянный эмулятор
   Остановить — останавливает эмулятор
   Проверить водителей — аналог npm run check
   Один проход убран из панели: используйте «Запустить» или «Проверить»

4. Если в проекте добавлен пункт меню «Эмулятор водителей», он открывает эту панель.
   Важно: браузер сам не может запустить node-процесс, поэтому panel.bat нужно открыть один раз.

НОВОЕ: движение по заказу
После того как пассажир выбрал водителя, эмулятор будет двигать его координаты к точке подачи, отправлять статус прибытия, а после старта поездки двигать машину к конечной точке. Настройки скорости и автостарт/автозавершение лежат в config.json -> tripSimulation.
