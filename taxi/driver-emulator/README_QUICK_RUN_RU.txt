Быстрый запуск теперь автоматический:

1. Распакуй архив.
2. Открой driver-emulator/panel.bat.
3. Всё остальное эмулятор делает сам:
   - проверяет готовых водителей;
   - если готовых меньше 5, сам создаёт недостающих тестовых водителей;
   - сам создаёт/проверяет машины;
   - сам запускает симуляцию.

Отдельно npm run register запускать не нужно.

Что важно по логике:
- offer/предложение/межгород и voting: бот только отправляет кандидатов, пассажир выбирает водителя сам.
- пока пассажир не нажал «Выбрать», эмулятор не начинает движение и не выбирает первого водителя.
- после выбора пассажиром выбранный водитель едет к клиенту, нажимает «на месте», ждёт 5 секунд, стартует поездку, доезжает и завершает её.
- обычный заказ можно брать напрямую, потому что там нет списка предложений.
- voting стартует подбором кода 1-9, если backend не вернул реальный код.
- при запуске эмулятор чистит старые активные заказы тестовых аккаунтов, чтобы аккаунты не зависали.

Если backend не даст создать машину, смотри файл:
driver-emulator/data/registration-last-result.json
